## Reel layout (rule from Toko, 3 Nov 2026)

Every Reel uses the full-width layout. Don't use the old small-card layout (app shown at ~¾ width and half the height, with empty space below).
* 1080×1920. Headline band at the top, ~380 px tall, dark background `#0b0f17`: headline Inter ExtraBold ~68 px, white with the key word in amber `#f59e0b`; subtitle ~38 px in grey `#aab3c2`; small „demo, dane przykładowe” label bottom right of the band.
* Under the band the raw clip fills the **full width (1080 px)**, 1:1 scale, cropped to 1540 px tall. Shift the crop down (e.g. 250–300 px on dashboard shots) so the key card sits above y≈1600 and isn't hidden under Instagram's caption.
* End card and cover use the same full-width look (cover = a frame from the video, not the old card).
